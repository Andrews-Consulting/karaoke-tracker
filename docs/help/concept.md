Fundamental concepts that this app supports: 
I sing different songs at different venues (locations)
I don't want to sing the same songs over and over at a venue.
My catalog represents all of the songs that I can sing (or want to try)
Besides managing my list of songs for tonight, I want to work on a list for next time at this venue.

1. Set the venue. As you mark a song 'sung', the venue and date are tracked.
2. Setlist choice 
    Tonight's designated setlist operates as follows
        Up next
            kj - full size screen showing the song and artist.
            Sang it - marks the song sang and displays the next song in kj mode
        upcoming list
            click - detail information about the song
            right swipe
                park - moves it to next time list (for when someone sings a song in your list)
                remove - removes the song from tonight's list
            drag handle (6 dots on the left) - allows you to grab and reorder the list.
    Any other setlist 
        you can make this list the active list for tonight.
        the + sign adds this song to 'tonight's active list'
        swipe left to expose delete, which removes the song from the displayed list
        click to see song details

6. Search - find a song to add to the current list (from your catalog)
