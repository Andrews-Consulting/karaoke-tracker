# Mic Jaunt: user stories

Everything the app does today, written as what the singer wants and why, without saying how the screens look. One story per behaviour; the ID in brackets points at the matching row in [REQUIREMENTS.md](REQUIREMENTS.md). The singer is the only user: this is a personal app on one phone, used standing at a bar table with one hand, often in a dark room with a drink in the other.

## A night out

- As a singer, I want to say which venue I am at tonight, so that everything I see is about this place: what I have sung here and when. (R37)
- As a singer, I want a set to always be open for tonight, chosen for me from the lists I have for this venue or started fresh and dated, so that I can start adding songs without setting anything up first. (R47)
- As a singer, I want any of my lists to be usable at any venue, with the ones I made for this venue offered first, so that a list I built for one bar is not locked away when I am somewhere else. (R56)
- As a singer, I want to search and filter my songs and put one on tonight's set, or take it off, with a single tap, so that building the set is as fast as thinking of the song. (R48)
- As a singer, I want to see tonight's set in order and move songs around, so that I can plan what comes next while the night unfolds. (R49, R61)
- As a singer, I want to mark a song as sung the moment I finish it, so that it is logged for this venue and today and drops off the set without my doing anything else. (R49)
- As a singer, I want to park a song I did not get to for next time at this venue, so that it is waiting for me the next time I am here. (R49)
- As a singer, I want to see what I have sung here tonight and on earlier nights, grouped by date, so that I know what the room has already heard from me. (R50)
- As a singer, I want to undo a sing I logged by mistake tonight and have the song go back to the top of the set, so that a mis-tap does not cost me the song. (R50)
- As a singer, I want to show a song's title, artist and key to the KJ in big type, so that I can hand my phone across a loud room instead of shouting. (R54)
- As a singer, I want my search, filters and sort to still be there when I come back to the songs from another part of the app, or after the app reopens, so that I do not rebuild them every time I glance at something else. (R53)
- As a singer, I want to pick a song at random from whatever my current search and filters leave, so that I can break a decision deadlock. (R13)

## Finding the right song

- As a singer, I want to search my songs by title or artist as I type, so that I can find a song in a few letters. (R10)
- As a singer, I want to see, for each song, how many times and how recently I sang it at this venue, so that I can avoid repeating myself here. (R37, R8)
- As a singer, I want to narrow my songs to those I have never sung at this venue, or not since a date I choose, so that I only see songs this room has not heard, or has not heard lately. (R41, R52)
- As a singer, I want to narrow my songs by tag, status, rating, genre and decade, combining them with my search, so that I can get to "upbeat 80s songs I sing well that are not retired" quickly. (R11, R42)
- As a singer, I want to sort my songs by title, artist, rating, how long since I sang them here, when I added them, genre or decade, so that the order suits what I am deciding. (R12, R42)
- As a singer, I want to see how many songs match and how many filters are on, and clear the filters in one move, so that I always know how narrow my view is. (R69)
- As a singer, I want the songs to appear at once and the search to keep up with my typing even with a thousand songs, so that the app never makes me wait at the table. (R34)

## My songs

- As a singer, I want to add a song with just its title and artist, so that capturing a new idea takes seconds. (R1)
- As a singer, I want to be told when a song I am adding is already in my songs, with the choice to open it or add it anyway, so that I do not end up with duplicates by accident. (R9)
- As a singer, I want titles, artists, the original year and a genre suggested as I type a new song, from an online music database when I am online, with the option to switch that off, so that I do not type and look things up by hand. (R35, R63)
- As a singer, I want to see everything about a song in one place and act on it from there: edit, delete, show it to the KJ, or look it up on the web, so that one song's details are never scattered. (R70)
- As a singer, I want to edit any detail of a song, or delete it after confirming, with its history and list entries going with it, so that my songs stay accurate and tidy. (R2)
- As a singer, I want to keep free-text notes on a song, such as "skip the bridge" or "starts cold", so that I remember how to perform it. (R3)
- As a singer, I want each song to carry a genre and a year, so that I can balance a night across styles and decades. (R36)
- As a singer, I want to tag songs with my own words, such as duet or crowd-pleaser, so that I can group them in ways no fixed field anticipates. (R5)
- As a singer, I want to record the key change I use for a song, so that I can set the machine right without remembering. (R6)
- As a singer, I want to mark a song as a go-to, something to try, or retired, with a new song carrying no mark until I decide, so that my list reflects where each song stands with me. (R7, R64)
- As a singer, I want to rate how well I sing each song from 1 to 5, so that I can lean on my best songs when it matters. (R4)
- As a singer, I want to look a song up on the web to listen to it, so that I can practise or check it away from the venue. (R38)

## Lists for later

- As a singer, I want to create, rename and delete setlists, each labelled for a venue or for anywhere, so that I can prepare for particular places and for any night. (R14)
- As a singer, I want to put a song on several lists and take it off any of them, so that lists stay independent. (R15)
- As a singer, I want to drag songs into order on a list, with a way to make long moves without dragging, so that the running order is mine. (R16)
- As a singer, I want songs on a list that I have already sung at its venue to be flagged with the date, so that I can see at a glance what the list still has to offer there. (R43)
- As a singer, I want to see a list's mix by genre and decade, so that I can tell whether a night will feel varied. (R44)
- As a singer, I want a list filled with songs I have never sung at its venue, spread across genres and decades, so that a fresh, varied set is one request away. (R45)
- As a singer, I want to merge one list into another, keeping only the songs the other does not already have, so that lists that have grown apart can be brought back together. (R59)
- As a singer, I want to go from a list straight to finding songs for it, so that filling a list uses the same search and filters as everything else. (R57)
- As a singer, I want the list I was working on to still be open if I step away for a few minutes, so that a glance at something else does not lose my place. (R60)

## Venues and history

- As a singer, I want to add, rename and delete venues, with a venue that has history protected from deletion, so that the places I sing stay accurate and my history stays intact. (R40)
- As a singer, I want to log a sing by hand for any date and venue, finding the song by typing, with today offered as the date, so that I can record a night after the fact or correct the record. (R8, R71)
- As a singer, I want to see, per venue and across all venues, each song with how often and how recently I sang it, so that I know my history anywhere. (R8)
- As a singer, I want to open a song's history at a venue to the individual sings and delete one, so that a mis-tap from an earlier night can be undone. (R72)

## Keeping my data

- As a singer, I want everything to live on my phone with no account and no server, so that my repertoire is private and works with no signal. (R18)
- As a singer, I want the phone asked to keep my data permanently, and to see whether it agreed, so that the browser does not quietly clear years of history. (R19)
- As a singer, I want to save a complete backup as one file, and on my phone hand it straight to Files, AirDrop or Mail, so that a lost or replaced phone does not mean a lost repertoire. (R20, R62)
- As a singer, I want to check what a backup file holds and how it compares with my phone, without restoring it, so that I can trust a backup before I need it. (R62)
- As a singer, I want to restore from a backup after confirming, so that a new phone, or a mistake, is recoverable. (R21)
- As a singer, I want a reminder when my last backup is more than a month old, with a way to put it off, so that backups happen without my remembering. (R25)
- As a singer, I want to be told that songs entered in the browser do not follow the app to the Home Screen, and offered a way to move them, so that I do not lose work when I install the app. (R65)
- As a singer, I want to import my songs from a spreadsheet, including which venue I sang each at and when, with duplicates and bad rows skipped and reported, so that a repertoire kept elsewhere comes across in one go. (R22, R46)
- As a singer, I want to export my songs as a spreadsheet, so that my list is mine to use in other tools. (R23)
- As a singer, I want to print my songs, a list or a venue's history cleanly, so that I can carry paper when I want to. (R24)

## The KaraFun catalog

- As a singer, I want to load the catalog file that KaraFun publishes, see when I loaded it and how large it is, and replace or remove it later, so that I know what the bar's machine can play without the app ever contacting KaraFun. (R66)
- As a singer, I want to search the KaraFun catalog by title, artist, genre, decade, duet, explicit and language, so that I can discover songs I could sing that I have not thought of. (R67)
- As a singer, I want to add a song from the catalog to my songs, or straight onto tonight's set, with its details filled in, so that discovering and planning are one motion. (R67)
- As a singer, I want my songs marked when KaraFun has them, kept up to date whenever I load the catalog, and filterable, so that I can tell which of my songs a KaraFun venue can actually play. (R68)

## Using it as an app

- As a singer, I want to install it on my home screen and have it open full screen like any app, so that it is one tap away at the bar. (R26, R29)
- As a singer, I want it to work fully with no connection once installed, so that a basement bar with no signal is no problem. (R27)
- As a singer, I want it served securely from a plain address, so that installing and updating need nothing but a browser. (R28)
- As a singer, I want to be told when a new version is ready and reload when I choose, so that updates never interrupt a night. (R30)
- As a singer, I want to see which version I have, so that I can tell whether an update arrived. (R73)

## Look and feel

- As a singer, I want everything reachable with one thumb, with targets I can hit in a dim, noisy room, and the back gesture returning me within the app rather than out of it, so that I can use it standing with a drink in my other hand. (R31)
- As a singer, I want the content to start at the top of the screen with no title bar, and the bottom controls to show where I am, so that the small screen is spent on songs. (R58)
- As a singer, I want a dark look by default with a light option and a choice to follow the phone, and a choice of accent colour, so that it is comfortable in a dark bar and still feels like mine. (R32, R51, R55)
- As a singer, I want it to read well on a laptop too, so that tidying my songs at a desk is pleasant. (R33)
